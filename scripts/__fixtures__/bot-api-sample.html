Bot API 9.9

  • Added the TestType object.

Available types

TestType

This object represents a test type.

Field Type Description
identifier Integer Unique identifier
photo PhotoSize Optional. The photo & its caption
rows Array of Array of KeyboardButton Optional. Button rows
payload InputFile | String File to send; pass a <file_id>
always True Optional. Always True

Stickers

Prose section whose table must never leak into TestType above it.

Field Type Description
chat_id Integer Leaked field that must NOT land on TestType
reply_markup InlineKeyboardMarkup Optional. Another leaked field

AbstractType

Serves as the base type for other objects and documents no fields.

NextType

Second concrete type, placed right after the table-less one.

Field Type Description
name String Name of the thing

EmptyType

FloatType

Has a Float field.

Field Type Description
horizontal Float Wavelength in meters

Available methods

sendMessage

Use this method to send text messages.

Parameter Type Required Description
chat_id Integer or String Yes Unique identifier for the target chat
text String Yes Text of the message
business_connection_id String Optional Connection on behalf of which the message is sent

legacyMethod

Older 3-column layout that marks optionality with square brackets.

Parameter Type Description
chat_id Integer Unique identifier for the target chat
[disable_notification] Boolean Sends the message silently

getMe

Returns basic information about the bot in form of a User object.

Sending files
