# telegram-bot-node

Zero-dependency TypeScript-first Telegram Bot framework mirroring `python-telegram-bot` (PTB) API.

## Features

- 🚀 **Zero required runtime dependencies** (uses Node.js 22+ built-ins: `fetch`, `node:sqlite`, etc.)
- 🐍 **PTB API compatibility**: Familiar handlers, filters, and callback context structure
- 🔒 **Type-Safe**: Full TypeScript coverage with strict mode
- ⚡ **High Performance**: Lightweight and modular

## Documentation

For full API reference and documentation, see TypeDoc generated documentation in `docs/` or run `npm run docs`.
